Changes made for this project
-----------------------------
* Converted the 70 weather-condition SVG icons (100-999) into 40x40 4-bit
  alpha (A4) bitmaps for LVGL.
* Added an icon-code lookup table so the real-time weather page can select
  the exact `icon` code returned by the QWeather API.
* Generated by scripts/gen_weather_icons.py; see that script for details.

The bitmaps are stored in components/assets/image/dida_weather_icons.c.

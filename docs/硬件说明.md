# 硬件说明

本文件记录 DIDA 的硬件事实与接线。
**引脚号的唯一事实来源是
[`components/board/include/board/board_config.h`](../components/board/include/board/board_config.h)**；
本文只解释“实物怎么接”和“为什么这样接”，改板子时先改 `board_config.h`。

## 1. 整机

| 项目 | 说明 |
|---|---|
| 主控 | 合宙 AirM2M Core / ESP32-C3，4 MB Flash，**无 PSRAM** |
| 屏幕 | 2.4" TFT，240×320，ST7789V，10 脚 FPC，**无触摸** |
| 交互 | 单实体按键（GPIO8，内部上拉，按下为低） |
| 光敏 | GL5506 / 5506 5mm 光敏电阻 + **10 kΩ** 分压电阻 → GPIO0 / ADC1_CH0 |
| 状态灯 | GPIO12（板载 D4，**高电平点亮**；D5 在 GPIO13，备用） |
| 供电 | USB-C 5V → 板载 3.3V；逻辑与背光都使用 3.3V |
| 固件 | ESP-IDF v6.1，双 OTA 槽各 1.75 MB |
| 调试 | ESP32-C3 原生 USB Serial/JTAG；经典版另有 CH343 |

## 2. 屏幕与 SPI

### 2.1 FPC 10 脚定义

面板规格书记录为 **WM_GMT024-01**（2.4" 240×RGB×320，ST7789V）。
实物 10 脚定义：

| FPC 脚 | 名称 | 接到 | 说明 |
|---|---|---|---|
| 1 | GND | GND | |
| 2 | RESET | GPIO5 | |
| 3 | SCL | GPIO2 | SPI 时钟 |
| 4 | RS / DC | GPIO4 | 数据/命令 |
| 5 | CS | GPIO7 | 片选 |
| 6 | SDA | GPIO3 | SPI 数据 |
| 7 | SD0 | 不接 | 4 线 SPI 用不到；也意味着**没有读回** |
| 8 | VCC | 3.3V | 逻辑电源，**不串电阻** |
| 9 | LEDA / A | 3.3V 经 10Ω | 背光正极 |
| 10 | LEDK / K | NMOS 漏极 D | 背光负极，低侧开关 |

> `LEDK` 接 NMOS 漏极 D（低侧开关），不是直接接 GND。
> `LEDA` 的 10Ω 是**背光限流电阻**，不是逻辑电源电阻。

### 2.2 SPI 与显示参数

| 项 | 值 |
|---|---|
| SPI 模式 | 0 |
| 像素时钟 | 27 MHz |
| 颜色格式 | RGB565 |
| BGR 元素顺序 | `false`（RGB） |
| 反色 | `false` |
| 字节交换 | `true`（`swap_bytes`） |
| 绘制缓冲 | 240×32，单缓冲，RGB565 + DMA |
| 读回 | **不支持**：`miso_io_num = -1`，FPC 的 SD0 也没接 |

`swap_bytes=true` 且 BGR=0 是这块面板在 `esp_lcd` + LVGL 下唯一正确的组合；
RGB565 的 5-6-5 字段不按字节对齐，不要照搬其它显示库的设置。

## 3. 背光：NMOS + 10Ω

### 3.1 面板背光规格

- 4 颗白光 LED **并联**，每颗额定 **15 mA**，总额定 **60 mA**。
- 模块没有背光驱动 IC，`LEDA`/`LEDK` 就是 LED 的正负极。
- `Vf ≈ 2.9~3.1 V`，3.3 V 下可用余量只有 0.2~0.4 V。

### 3.2 当前接线

```text
主板 3.3V ──┬──────────────── VCC(8)          ← 逻辑供电，单独一路
            │
            └──[10Ω]──────── LEDA(9) ─┐
                                       │  面板内 4 颗 LED 并联
                                 LEDK(10) ─┘
                                       │
                                       D
                                       │
   GPIO6 ──[100Ω]──┬── G            AO3400A
                   │                  │
                [100kΩ]               S ──── GND
                   │
                  GND
```

| 元件 | 值/型号 | 说明 |
|---|---|---|
| 限流电阻 | **10Ω** | 串在 `3.3V → LEDA` 之间 |
| N-MOS | **AO3400A**（丝印 A09T） | SOT-23，逻辑电平，低侧开关 |
| 栅极串阻 | **100Ω** | 抑制振铃，可选但建议 |
| 栅极下拉 | **100kΩ** | 保证 GPIO 未驱动时关断，推荐 |

**关键点**：`D` 只接 `LEDK`，`S` 只接 `GND`，`D/S` 不能反；
100kΩ 下拉要靠近 MOS；10Ω 只串在 LEDA 这一路，不能并在 VCC-GND 上。

### 3.3 电流与亮度

当前使用 **10Ω**：

| 限流电阻 | 总电流 | 每颗 LED | 占额定 | 说明 |
|---|---|---|---|---|
| **10Ω** | **≈30 mA** | **7.5 mA** | **50%** | 当前使用值 |

`Vf` 取 2.9~3.1 V 时，10Ω 对应约 20~40 mA（33%~67% 额定），仍在安全侧。
实测：**四档正常、最高档连续运行不发热、过夜稳定**。
10Ω 已经够用，不建议再降低阻值。

### 3.4 固件

低侧 NMOS 由 GPIO 高电平导通，与现有语义一致：

- `0` = 灭，`255` = 最亮
- PWM 5 kHz / 8 位
- 固定档 `80 / 160 / 255`，AUTO 档下限 `26`
- **固件不需要改**

如果以后觉得档位分布不合适（低档偏暗、高档偏亮），改
`components/backlight/include/backlight/backlight_policy.h` 里的
`kFixedDuty` / `kMinAutoDuty` 即可，硬件不用再动。

### 3.5 不能直接改 5V

同样的 10Ω 在 5 V 下是 `(5 − 3.0)/10 = 200 mA`，会烧 LED。
要改 5 V 必须重新计算限流电阻，并先确认面板背光额定电流。

## 4. 按键、光敏、状态灯

### 4.1 按键

- GPIO8，内部上拉，按键另一端接 GND，**按下读到低电平**。
- 固件在 LVGL 任务里每 10 ms 轮询一次，不使用中断。
- 手势：单击/双击/长按，具体行为见 [README](../README.md) 的按键表。

### 4.2 光敏

- 型号：**GL5506 / 5506**（5mm）；典型亮阻约 **4~7 kΩ @10 lx**（不同厂家/批次有差异），暗阻 **>0.2 MΩ**。
- GPIO0 / ADC1_CH0，12 位，`ADC_ATTEN_DB_12`。
- 固件预期 **ADC 读数越大越暗**，所以 LDR 应接在 `ADC → GND` 一侧，
  分压电阻接在 `3.3V → ADC` 一侧：

  ```text
  3.3V ──[ R ]──┬── GPIO0 / ADC1_CH0
                │
             [ LDR ]
                │
               GND
  ```

- 分压电阻 **10 kΩ**（SMD 丝印 `103`）。
  10 kΩ 时：亮态约 1.1~1.4 V，暗态约 3.1 V，正好覆盖 12 dB 衰减的 ADC 量程。
- 本机已实测：AUTO 档方向正常，按上图接线（**10 kΩ 在上、LDR 在下**）。
- 复现时注意：不少网上教程把 LDR 接在 3.3V 侧、10 kΩ 接 GND 侧；
  那种接法在本固件上会让 AUTO 反向。方向反了不用改代码，把两者对调即可。
- AUTO 档把 ADC 读数映射到 0..255，并有 `kMinAutoDuty = 26` 的下限，
  避免暗环境下屏幕全黑、用户看不见按键反馈。

### 4.3 状态灯

- 板载 **D4 = GPIO12**、**D5 = GPIO13**，两颗都是**高电平点亮**
  （合宙官方文档 Table 4-1）。
- `board_config.h` 里的 `kStatusLedPin = GPIO12` 就是 D4；当前固件没有驱动它，
  需要时把 GPIO12 设为输出、写高电平即可点亮。
- GPIO12/13 同时是外部 SPI Flash 的 `HOLD#`/`WP#`。本板使用 **DIO** Flash 模式
  （`CONFIG_ESPTOOLPY_FLASHMODE_DIO=y`），所以这两个脚可以当普通 GPIO；
  如果改成 QIO，会和 Flash 冲突，不能再用作 LED。

## 5. 板型差异与烧录

合宙 ESP32-C3 有两个版本，USB 通路不同：

| | **简约版** | **经典版** |
|---|---|---|
| USB 通路 | USB-C 直连芯片原生 USB（GPIO18/19） | USB-C → **CH343P** → UART0 |
| 电脑识别 | Espressif 原生 USB，VID `303a` | WCH 串口，VID `1a86:55d3` |
| 驱动 | macOS/Linux/Windows 免驱 | 需要 WCH 驱动 |
| macOS 26/27 | 正常 | 官方驱动是 Intel kext + 需 Rosetta，加载受限 |

- 主设备是**简约版**，macOS 上即插即烧。
- 经典版在 macOS 新版上可能烧不进；可改用 Windows/Linux，或外接 USB-TTL 走 UART，
  或飞线接 `GPIO18(D−)/GPIO19(D+)` 走原生 USB。
- UART0 默认 `TX = GPIO21`、`RX = GPIO20`（以板子丝印为准）。
- 烧录：`idf.py -p <端口> flash`；改过 `partitions.csv` 后必须 `idf.py flash -a` 全量烧录。

## 6. 已知限制

- **无触摸**，交互只有单按键。
- **无屏幕读回**：SPI 的 MISO/SD0 没接，不能从 ST7789 读 GRAM；
  如需截图，只能从 LVGL 的渲染结果导出。
- **无 PSRAM**：240×320×2 = 150 KB 的整屏缓冲要占用内部 DRAM，做截图/大缓冲时要先确认堆余量。
- 背光当前为额定的 50%，不建议为了再亮一点降低阻值。
